# Green Lab Energy Audit

Standard-library Python tool that estimates fictional lab assets' annual energy, cost, and emissions from an editable inventory. The ranking is for human review and never recommends switching equipment off.

```bash
python green_lab_energy_audit.py
python -m unittest discover -s tests -v
```
