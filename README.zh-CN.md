# Green Lab Energy Audit

这个小工具将实验室资产清单转成年度用能、费用和排放量的估算，并按估算用能从高到低排列，供团队讨论哪些假设值得核实。它聚焦盘点与估算，不生成设备操作或停机建议。

## 运行

需要 Python 3.9 或更高版本，无第三方依赖。

```bash
python green_lab_energy_audit.py
python -m unittest discover -s tests -v
```

首次运行会创建 `data/assets.csv`。该清单是可编辑的虚构示例；后续运行读取现有文件，不会覆盖你的修改。列为 `asset_id,asset_name,category,rated_kw,annual_hours,load_factor`。也可使用 `--inventory` 指定清单。参数 `--price-yuan-kwh` 和 `--emission-factor-kg-kwh` 可替换默认占位系数。结果写入 `results/report.json` 和 `results/ranked_assets.csv`。

## 术语

- **额定功率（kW）**：设备铭牌上的功率，不等同于实际平均功率。
- **年运行小时数**：估算设备一年运行的时长，取值范围 0 至 8760。
- **负载系数**：估算平均负载相对额定功率的比例，范围 0 至 1。
- **排放因子**：单位用电对应的温室气体排放估值，需按适用地域、年份和口径查证。

估算公式为 `额定功率 × 年运行小时数 × 负载系数`。费用与排放量分别乘以电价和排放因子。

## 数据和边界

示例资产、运行小时、电价 `0.72 元/kWh` 和排放因子 `0.536 kgCO2e/kWh` 都是演示用假设，不是对任何学校的测量或官方因子。铭牌估算误差可能很大；采购、科研保存、通风和安全要求也未建模。排名只用于人工检查清单假设，绝不能据此要求关闭或改变任何设备。真正的盘点应由实验室负责人和设施人员核实数据与工作要求。
